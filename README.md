# SmartFactoryStockControl

## 프로젝트 주제
**Smart Factory Stock Control System Simulation utilizing Beagle and OMX-F Robots**

## 프로젝트 배경
금속가공/소형 기계부품을 다품종 소량생산하는 **50인 미만 중소기업**을 타겟으로 합니다.  
기초 CCTV는 보유하고 있으나 AI 기반 재고/흐름 분석이 없는 환경에서, **QC 검사 + 포장 경계 지점**의 재고 단절 문제를 해결하는 시뮬레이션 프로젝트입니다.

## 타겟 및 페인 포인트
| 구분 | 내용 |
|---|---|
| 타겟 기업 | 금속가공/소형 기계부품 다품종 소량생산 중소기업(50인 미만) |
| 현재 상태 | CCTV 기반 모니터링은 가능하나 AI 분석 자동화 부재 |
| 주요 페인 포인트 | QC 검사와 포장 경계 지점에서 부품 부족 인지/보급 지연 발생 |

## 시뮬레이션 프레임워크(운영 시나리오)
1. 공장 각 생산라인에서 부품 재고를 감지합니다.
2. 부족한 부품이 발생하면 시스템이 즉시 인지합니다.
3. 재고 보관소의 OMX-F 로봇에 신호를 전달하고, 대시보드에 현황을 기록합니다.
4. 재고 보관소 OMX-F 로봇이 부품을 Beagle 로봇에 적재하고, Beagle이 생산라인으로 운반합니다.
5. 생산라인 OMX-F 로봇이 Beagle 적재 부품을 하차해 생산라인으로 이동시킵니다.

## 로봇 구성 정보 요약

### 1) Beagle 로봇
- 링크: https://robomation-shop.co.kr/category/%EB%B9%84%EA%B8%80ai%EB%A1%9C%EB%B4%87/140/
- 요약:
  - 공장 내 자율 주행 기반 이송 로봇(AMR) 용도로 활용 가능한 플랫폼
  - 부품/자재를 생산라인 간 운반하는 물류 이동 축 역할
  - 실제 적용 시 탑재 하중, 주행 안정성, 관제 연동 항목은 공식 판매/기술 페이지 기준으로 검증 필요

### 2) OMX-F 로봇
- 링크: https://docs.robotis.com/docs/systems/omx/introduction/
- 요약:
  - Robotis OMX 시스템군의 산업/제조 자동화 적용 로봇 플랫폼
  - 본 프로젝트에서는 적재/하차 및 라인 투입 전환 작업을 담당하는 고정 거점 로봇 역할
  - 연동 시 인터페이스/작업공간/안전설정은 공식 문서 기준으로 설계 필요

## 시스템 구성(구조화 정보)
| 모듈 | 주요 기능 | 입력 | 출력 |
|---|---|---|---|
| 재고 감지 모듈 | 생산라인 재고 실시간 감지 | 라인 센서/CCTV 분석 결과 | 품목별 재고 상태 |
| 부족 인지 모듈 | 임계치 미만 재고 판정 | 재고 상태, 임계치 정책 | 부족 이벤트 |
| 관제 대시보드 | 이벤트 기록/가시화 | 부족 이벤트, 로봇 상태 | 알림, 작업 이력 |
| 보관소 OMX-F | 부품 적재 작업 | 부족 이벤트, 작업 지시 | Beagle 적재 완료 신호 |
| Beagle 이송 | 생산라인까지 부품 운반 | 적재 완료 신호, 경로 | 도착 신호 |
| 라인 OMX-F | 하차 및 라인 투입 | 도착 신호, 품목 지시 | 라인 공급 완료 |
