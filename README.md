# Smart Factory Stock Control System Simulation

Smart Factory Stock Control System Simulation utilizing **Beagle** and **OMX-F Robots**

## 1) 프로젝트 개요
- **주제**: Beagle + OMX-F 로봇 기반 스마트 팩토리 재고 제어 시뮬레이션
- **목표**: 생산라인 재고 부족을 자동 인지하고, 로봇 연계를 통해 공급 시간을 단축
- **적용 환경(타겟 기업)**:  
  금속가공/소형 기계부품을 **다품종 소량생산**하며, 기초 CCTV는 있으나 AI 분석 체계가 없는 **50인 미만 중소기업**

## 2) 문제 정의 (Pain Point)
- **핵심 병목 구간**: **QC 검사 + 포장 경계 지점**
- **문제 상황**:
  - 생산라인별 부품 소진 시점 파악 지연
  - 재고 보관소와 생산라인 간 수동 커뮤니케이션으로 대응 지연
  - 부품 이송 상태 추적/기록 체계 미흡

## 3) 시스템 동작 프레임워크
1. 공장 각 생산라인에서 부품 재고를 감지한다.
2. 부족한 부품이 발생하면 시스템이 이를 인지한다.
3. 재고 보관소의 OMX-F 로봇에 신호가 전달되고, 대시보드에 현황이 기록된다.
4. 재고 보관소 OMX-F 로봇이 부품을 Beagle 로봇에 적재하고, Beagle이 생산라인으로 운반한다.
5. 생산라인의 OMX-F 로봇이 Beagle 적재 부품을 하역하여 라인 투입 위치로 이동시킨다.

## 4) 로봇 구성 요소 요약

### 4.1 Beagle 로봇
- **링크**: https://robomation-shop.co.kr/category/%EB%B9%84%EA%B8%80ai%EB%A1%9C%EB%B4%87/140/
- **역할 요약**:
  - 생산라인과 재고 보관소 사이를 이동하는 **모바일 운반체(AMR 성격)**
  - 부품 이송 요청에 따라 지정 위치로 자율/반자율 이동
  - 이송 단계의 상태(출발/도착/대기)를 대시보드 연동 데이터로 활용 가능

### 4.2 OMX-F 로봇
- **링크**: https://docs.robotis.com/docs/systems/omx/introduction/
- **역할 요약**:
  - 보관소/생산라인 양측에서 수행되는 **상하차(적재·하역) 매니퓰레이션 로봇**
  - 정해진 작업 포인트에서 반복적인 부품 핸들링 자동화
  - Beagle과 연계해 “보관소 → 운반 → 라인 투입”의 이송 체인을 구성

## 5) 구조화 정보

### 5.1 프로세스 엔터티
| 엔터티 | 설명 | 입력 | 출력 |
|---|---|---|---|
| 재고 감지 모듈 | 라인별 재고 상태 모니터링 | CCTV/센서 기반 재고 데이터 | 부족 이벤트 |
| 이벤트 인지/판단 모듈 | 부족 이벤트 발생 여부 판단 | 재고 데이터, 기준 임계치 | 이송 작업 지시 |
| 대시보드 | 작업 상태 기록 및 가시화 | 이벤트/로봇 상태 로그 | 운영 현황 화면 |
| 보관소 OMX-F | 부품 적재 작업 | 이송 작업 지시 | Beagle 적재 완료 신호 |
| Beagle | 부품 운반 작업 | 적재 완료, 목적지 정보 | 생산라인 도착 신호 |
| 라인 OMX-F | 하역 및 라인 투입 | 도착 신호 | 라인 공급 완료 신호 |

### 5.2 이벤트 흐름
| 단계 | 트리거 | 수행 주체 | 결과 |
|---|---|---|---|
| S1 | 재고 임계치 도달 | 재고 감지 모듈 | 부족 이벤트 생성 |
| S2 | 부족 이벤트 수신 | 판단 모듈/대시보드 | 이송 지시 + 상태 기록 |
| S3 | 이송 지시 수신 | 보관소 OMX-F | Beagle 적재 |
| S4 | 적재 완료 | Beagle | 생산라인으로 운반 |
| S5 | 라인 도착 | 라인 OMX-F | 하역 및 라인 투입 완료 |
